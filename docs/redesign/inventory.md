## Gaps across the whole app (found in the audit)

- No toast system: feedback is inline notices, some flows `window.location.reload()` after success. **Build:** a Sonner-grade toaster (stacked, swipe to dismiss, pauses when hidden) and replace reloads with optimistic updates.
- No Sheet, Popover, AlertDialog; Tooltip is mounted and never used. **Build:** Tray (Family-style: one task per tray, height change marks each step, morphs from its trigger), Popover, Tooltip with skip-delay.
- No clipboard anywhere (signing links, envelope IDs, hashes). **Build:** a copy button with a check that morphs back.
- No dark mode. **Build:** Carbon theme after primitives are done (tokens already grouped for it).
- No command menu, no keyboard shortcuts beyond Delete in the builder.
- Two parallel styling systems: shadcn `ui/` and a CSS component layer (`.panel`, `.pill`, `.btn-quiet`, `.field-input`, `.notice`, `.segmented`), plus raw hex in about 70 places. **Fold** the CSS layer into `ui/` primitives as each is rebuilt; remove raw colours.
- Very large client files (signing 2,206 lines, builder 1,841, envelope detail 1,376, signers 1,134). Split by section while redesigning.
- Signer reorder is up/down buttons only. **Build:** drag to reorder with a rigid row and springy neighbours, buttons kept for keyboard.
